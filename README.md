# 📱 Application Gestionnaire de Liste

Application mobile développée avec **React Native** et **Expo**, permettant de créer, gérer et organiser des listes directement depuis un appareil mobile.

Le projet met l'accent sur une expérience utilisateur simple et une **persistance locale des données** grâce à SQLite.

##  Fonctionnalités

-  Création et gestion de listes
-  Ajout, modification et suppression d'éléments
-  Gestion de l'état des éléments d'une liste
-  Persistance locale des données avec SQLite
-  Interface adaptée aux appareils mobiles
- Conservation des données entre les sessions
-  Fonctionnement entièrement local, sans dépendance à une API distante

## Technologies utilisées

| Technologie | Utilisation |
|---|---|
| **React Native** | Développement de l'application mobile |
| **Expo** | Environnement et outils de développement React Native |
| **TypeScript / JavaScript** | Logique de l'application |
| **SQLite** | Persistance locale des données |
| **Git / GitHub** | Gestion du code source et versionnement |
